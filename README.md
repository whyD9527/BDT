## 二、功能介绍

### 1. 解析与下载

- **多种目标**：`BV` / `AV` 号、番剧与课程的 `EP` / `SS` 号，以及 `b23.tv` 短链，粘贴进首页输入框即可解析。
- **画质与编码偏好**：可分别指定「优先分辨率」「优先编码」「优先音频质量」，也可让应用自动选择。
- **三种下载模式**：
  - **音视频**：分别下载视频流与音频流，再用 FFmpeg 合并成一个文件；
  - **仅视频** / **仅音频**：只取其中一路，省流量、也更快。
- **多线程分片下载**：大文件按 Range 分片并发；服务端不支持或出错时**自动回落到单线程**，不会因为一个分片失败就整体失败。
- **断点续传**：临时文件带边车信息，重试或重新添加时会复用已下载的部分。
- **下载限速**：可设置全局速度上限，也可设为不限速。
- **缓存线路**：内置多条线路（默认 / 阿里等），每条都能**一键测速**，用来绕开某些线路的慢速或限速。

### 2. 下载管理

- **两个列表**：「正在下载」与「已完成下载」，支持按时间、大小、标题等排序。
- **暂停 / 继续 / 取消**：单个任务可操作，也支持「全部暂停」「全部取消」。
- **通知栏控制**：下载进度常驻通知，可**全部暂停 / 全部取消**，**点通知直达下载管理**。
- **编辑态批量操作**：长按任意卡片进入编辑态，多选后可：
  - **重命名**：批量改文件名（校验非法字符与重名）；
  - **移动**：批量移动到下载目录下的子目录（**记录仍然有效，文件的 URI 不变**）；
  - **分享**：把已下载的文件分享给其它应用；
  - **删除**：删记录并删文件。
- **重复下载文件检查**：扫描下载目录，把「同一部视频存在多份副本」列出来交你确认清理——**只删副本、保留正式名那份**，并且**优先保留记录实际引用的那一份**，不会把记录清成「文件已丢失」。
- **文件状态标记**：记录里会标注「文件已丢失」，一眼看出哪些记录指向的文件已经不在。

### 3. 文件命名与存放

- **命名规则自定义**：用占位符拼出想要的文件名，例如
  `{title}`、`{p_title}`、`{author}`、`{p}`、`{aid}`、`{bvid}`、`{cid}`、`{collection_title}`；
  界面里会给出**警告提示**（非法字符、超长、重名等）。
- **目录可配置**：下载目录（默认 `Download/BDT`）、缓存目录都能改。
- **交付方式**：成品通过 MediaStore 写入下载目录，因此在**系统文件管理器、相册、其它应用**里都能正常看到与打开；同名旧文件会被**先挪开、写入成功后再清理**，避免在下载目录里堆出一串 `(1)`、`(2)` 副本。
- **字幕 / 弹幕**：可单独导出字幕（ASS / SRT）与弹幕文件。

### 4. 逐帧提取

- 从**已下载的记录**里挑一个视频导入（不用额外准备文件）；
- 拖动进度、按帧率精确定位，取到想要的那一帧；
- **导出逐帧图片**：选择导出目录后批量导出 **PNG（保持视频原始分辨率）**，可用于封面、截图或素材。

### 5. 其它工具与设置

- **网页解析**：直接解析 B 站网页链接，取出视频信息与可下载的流。
- **剪贴板自动识别**：复制一条 B 站链接后回到应用，会自动识别并询问是否解析
  （**只读剪贴板、不会清空或改写你复制的内容**；需要先在应用内同意隐私政策）。
- **设置备份 / 恢复**：把命名规则、平台、画质与编码偏好等导出为 **JSON** 存到下载目录，换机或重装后一键恢复。
- **存储管理**：查看应用与下载目录的空间占用、音视频文件总大小，列出下载目录文件（含子目录）并**标出没有记录的孤儿文件**。
- **诊断日志**：查看最近 500 行「交付 / 清理 / 失败」轨迹，并**一键导出**到下载目录，排查问题时直接发给开发者。
- **权限主动提醒**：覆盖安装后如果丢了「所有文件访问」或通知权限，**入队时会明确提示**该去哪里开启
  （缺少「所有文件访问」会导致新交付的文件入库异常、同名覆盖失效）。
- **多语言**：界面文案支持多语言，跟随系统语言切换。

## 三、安装

- 到 [Releases](../../releases) 下载签名 APK；
- 或到 [Actions](https://github.com/whyD9527/BDT/actions/workflows/build-apk-alpha.yml) 下载最近一次构建的
  `app-alpha-*-release.apk`（CI 产物仅供测试）。

系统要求：Android 8.0 及以上（推荐 Android 10+，以获得完整的存储访问体验）。

---

## 四、自行构建

```bash
git clone https://github.com/whyD9527/BDT.git
cd BDT
./gradlew :app:assembleAlphaRelease     # Release 变体
./gradlew :app:assembleAlphaDebug       # 调试变体
./gradlew test                          # 单元测试
```

需要 JDK 17+ 与 Android SDK；FFmpeg 等依赖由 Gradle 自动拉取。
