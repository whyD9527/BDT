### 一、铁律（写在仓库根 `AGENTS.md`，必读）

**社会实践是检验真理的唯一标准。** 本地校验 / 单测 / CI 双绿只是最低门槛；**真机没跑过就不算完成**。

- 判据必须是**客观证据**：`download-trace.log` 的具体行、`crash.log` 的条数与时间戳、
  `/data/app` 里本应用安装目录的时间戳与路径（确认装的是哪一版）、`Download/BDT/` 导出文件的真实内容；

- **安装 APK 只能由用户在真机上完成**（本侧没有安装入口）。

### 二、怎么发版（照做即可）

1. 本地校验：`python3 /tmp/validate_bdt.py`（注意：它有一条 `core_back` 的**已知误报**，可忽略）；
2. 推送：`GH_TOKEN=$(cat /tmp/ght) python3 tools/push_via_api.py --stage-all --message "…"`；
3. 等 CI：`Build APK (Alpha)` 双绿才算真绿 —— 判据是 **`Fallback to alphaDebug` = skipped**
   （`Assemble alphaRelease` 带 continue-on-error，**不能只看它**）；
4. bump `app/build.gradle.kts` 的 `versionCode`/`versionName` → 再推一次 → 建 tag `vX.Y.Z`（GitHub API）
   → `Release APK` 工作流出签名 APK → **写 Release 说明**（更新日志只写这里，README 不写）；
5. 交付用户装包 → 按铁律逐条真机复验。

### 四、已知真机坑（都踩过）

- **文字点按比坐标点按可靠**；键盘弹出会推动布局，坐标要重新 dump；
- 横滑可能被当成"退出"，页面状态也常被保存/恢复，**每次操作前先 dump 确认在哪个页面**；
- 后台化（按 Home）会触发 Activity 状态保存 → 路由缺 `@Serializable` 会崩（已在 3.3.7 修）；
- 覆盖安装**可能丢**「所有文件访问」与通知权限；**清空数据的新安装**会把隐私政策重置为"未同意"
  （此后剪贴板自动识别与更新检查都不会执行）；
- 往 `LazyColumn(…)` / `Scaffold(…)` 里插内容必须锚定**内容 lambda 的 `{`**，
  不能锚定调用名（`LazyColumn(` 之后先是参数，插错会报 `Unresolved reference 'item'`）。
